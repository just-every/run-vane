# Acceptance

Each clause in CONTRACT.md is accepted by the evidence below, run through a public door (route, command, built page or browser journey) on a built Worker with fakes only at paid or network edges. The status after each clause is the one recorded in CONTRACT.md's Status section at the judged commit; a build round moves a clause to done only when its evidence runs and passes.

## Existing guarantees

- `HTTP-001` One Worker with honest public and private doors (done): Request `/health`, `/vane.js`, an unknown path and every private route signed out on a built Worker. Health answers, the script is served, unknown paths return 404, and private routes return 401 or redirect to sign-in (`tests/vane.test.mjs`).
- `ACCESS-001` Owners approve, administrators prepare, members read (done): Invite an administrator and a member. The member cannot prepare a site, the administrator cannot approve or import, export is owner-only, and revoking the administrator ends their session (`tests/vane.test.mjs`).
- `ACCESS-002` Private doors refuse signed-out and cross-origin requests (done): Call every private GET and POST door signed out, signed out after sign-out, and with a foreign Origin. Each is refused with no write (`tests/vane.test.mjs`).
- `APPROVE-001` Prepared changes apply only on the owner's recorded approval (done): Prepare as an administrator, approve as the owner, then approve again; the second approval gets 409. Inspect the proposal for distinct preparer and approver (`tests/vane.test.mjs`).
- `COLLECT-001` A cookie-free script that sends only declared anonymous fields (done): Post an event from a foreign origin (403), with an extra personal field (400) and with a path carrying a query (400). A valid event is accepted (202) (`tests/vane.test.mjs`). In a browser, a default-mode pageview leaves no cookie and no storage entry; `#vane-ignore=on` writes only `vane_ignore` and excludes that browser, and `#vane-ignore=off` clears it. `/methodology` and the report's data inventory name both storage exceptions.
