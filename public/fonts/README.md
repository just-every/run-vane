# Fonts

Inter Tight (headings and the wordmark, variable 100–900), Inter (body, variable 100–900) and IBM Plex Mono (400, 500) are self-hosted WOFF2 files. Their SIL Open Font License texts are beside the files. Fontsource packages @fontsource-variable/inter-tight 5.3.0, @fontsource-variable/inter 5.3.0 and ibm-plex-mono 5.2.6 supply these files. Pages make no third-party font requests.
