# Vane contract

ACCEPTANCE.md defines the first release. Private handlers enforce native roles;
collection admits only configured anonymous fields. Agent commands prepare and
the owner approves. Analytics and import custody remain portable.

The public run site serves Vane's approved homepage, `/run` installation
instructions, repository Markdown documentation at `/docs`, and a not-found
page. It reads no installation data, loads only local assets, and has no demo
or sign-in action. Its Run and Docs actions are usable without JavaScript.

An installed instance keeps its Lobby at `/` and its existing authenticated
routes. Both surfaces use the shared Vane theme and locally served fonts.
The homepage's Fern figures are explanatory drawings, never seeded analytics.

Run-site deployment stays off behind `RUN_SITE_DEPLOY`. Existing edition,
package, Worker and database identifiers are preserved. The run site is
configured for run-vane.com; enabling deployment is a separate lane.
